# ESP32 ESC Passthrough

**Work in progress.** A port of [Betaflight's ESC passthrough](https://github.com/betaflight/betaflight) to ESP32, targeting ESP32-C3 (and later ESP32-S3) with ESP-IDF v6.1(?). So set target to one of these or change supported targets[*]() to include your board and hope it works.

DISCLAIMER: I'd probably only use this to read and write ESC settings i do not trust my own abilities enough to flash firmware with this just yet. 

Only tested on **Bluejay v0.21** so far, aM32 testing is planned soonish.

the goal is for this to support integration with [esp32-dshot](https://github.com/aroncullberg/esp32-dshot).
